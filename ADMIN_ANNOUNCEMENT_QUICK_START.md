# Quick Start: Sending Announcements to Farmers

## For Administrators

### Step 1: Go to Announcements
1. Log in to Admin Dashboard
2. Click: **Admin Panel** → **Announcements** → **Create New**

### Step 2: Fill in Basic Info
- **Title**: "Important Notice for All Farmers"
- **Content**: Your message here
- **Category**: Choose one:
  - `General` - Normal information
  - `Alert` - Urgent notice
  - `Weather` - Weather related

### Step 3: Choose Your Audience
**Option A - Send to Everyone**:
- Audience Scope: `All Farmers`
- Leave "Target Group" empty

**Option B - Send to Specific Group**:
- Audience Scope: `Specific Farmer Group`
- Target Group: Select the group (e.g., "Region A Farmers")

### Step 4: Set Publishing Options
- ☑ Check **"Publish Immediately"** to send now
- Or leave unchecked and set **Start Date** to schedule for later

### Step 5: Click Create!

---

## Farmer Experience

### Farmers will see announcements:
1. ✅ In the **Announcements** section
2. ✅ In the **Weather** section (if category is Weather or Alert)
3. ✅ Only if they belong to the target group (or it's for all farmers)
4. ✅ Only after the start date
5. ✅ Only before the expiry date

### Farmers won't see announcements:
- ❌ If they're in a different group (for group-specific ones)
- ❌ If not yet published
- ❌ If before start date
- ❌ If past expiry date
- ❌ If past end date

## Examples

### Example 1: Tell Everyone About Fertilizer Subsidy
```
Title: Fertilizer Subsidy Program - Apply Now!
Content: The government is offering 50% subsidized fertilizer...
Category: General
Audience: All Farmers
Publish: Immediately
```

### Example 2: Weather Alert for Region A Only
```
Title: Typhoon Warning - Region A
Content: Strong typhoon expected in 48 hours...
Category: Alert
Audience: Specific Farmer Group → "Region A Farmers"
Publish: Immediately
Expiry Date: 3 days from now
```

### Example 3: Schedule a Future Announcement
```
Title: Rice Planting Instructions
Content: Optimal planting time is next month...
Category: General
Audience: Specific Farmer Group → "Rice Farming Group"
Publish: Unchecked (let me schedule it)
Start Date: Next month, Sept 1st, 8:00 AM
```

## Troubleshooting

**Q: Farmers say they're not seeing my announcement**
- A: Check:
  1. Did you check "Publish Immediately"?
  2. Is today after the start date?
  3. Is today before the expiry date?
  4. Are THEY in the group you selected?

**Q: How do I stop showing an old announcement?**
- A: Either:
  - Set an **Expiry Date** (past date = don't show)
  - Or delete it (trash icon)

**Q: Can I target multiple groups at once?**
- A: Not yet - one announcement = one group (coming soon)

**Q: Can I save as draft?**
- A: Yes! Don't check "Publish Immediately" and don't set a start date. Edit it later.

## Key Reminder
The system ensures farmers only see:
- ✅ Announcements meant for everyone, OR
- ✅ Announcements for their specific group
- ✅ That are published
- ✅ That are currently active (between start and end dates)
