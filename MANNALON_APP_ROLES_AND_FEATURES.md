# Mannalon App - Roles and Features

## Roles

### 1. Super Admin
- Full system access.
- Can manage all admin features.
- Can manage users, including create, update, and delete operations.
- Can oversee farmers, crops, livestock, announcements, guides, market prices, weather content, and reports.
- Has access to system-wide analytics and administrative controls.

### 2. Admin
- Manages the operational side of the app.
- Can view, create, update, and delete farmer records.
- Can manage announcements, farming guides, weather advisories, and market price content.
- Can monitor all crops and livestock across the system.
- Can access reports, analytics, CSV export, and PDF export.
- Can manage land-related workflows and beneficiaries.

### 3. Farmer / User
- Regular app user focused on farm management.
- Can register and log in to the app.
- Can manage personal crop and livestock records.
- Can view announcements, guides, weather updates, and market prices.
- Can update profile and password.
- Can use messaging and AI chatbot assistance.

## Features

### Authentication Features
- User registration
- Secure login and logout
- Role-based redirection after login
- Password hashing and session protection

### Farmer Features
- Farmer home dashboard
- Announcements viewing
- Farming guides browsing
- Weather information access
- Market prices viewing
- Crop CRUD operations
- Livestock CRUD operations
- Personal profile management
- AI chatbot assistance
- Messaging and notifications

### Admin Features
- Admin dashboard overview
- Farmer management
- Farmer status management
- Announcements management
- Farming guides management
- Weather advisories management
- Market price management
- Crops monitoring
- Livestock monitoring
- Reports and analytics
- CSV export
- PDF export
- Land management and beneficiary distribution

### Super Admin Features
- All admin features
- User management
- Higher-level administrative control
- System-wide oversight

### AI Chatbot Features
- Farming advice responses
- Mannalon app navigation help
- Restricted scope for agriculture and app usage
- OpenRouter API integration with fallback demo responses

### Messaging Features
- Direct messages
- Broadcast messages
- Announcement-type messages
- Conversation threads
- In-app notifications
- Message statistics

## Access Summary
- Super Admin: full access plus user management.
- Admin: operational and content management access.
- Farmer / User: personal farm management and content viewing access.
